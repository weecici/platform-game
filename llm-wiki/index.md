# LLM Wiki: Parkour Game

This wiki is a persistent, interlinked collection of markdown files that sits between agents and raw sources.

## Rules for Agents

- **Read First:** Consult this wiki before diving deep into the codebase.
- **Maintain & Update:** When you learn something new, fix a bug related to architecture, or add a feature, update these files. Do not let this wiki get stale.
- **Synthesize:** Integrate new data into existing pages rather than just appending raw facts.
